# Ray Tracing on a CPU

This implements a CPU-based ray tracer, somewhat implemented using techniques based off the book 'Physically Based Rendering' (4th ed) but also incorporating implementation methods and inspiration from other places, including the Scratchapixel project and Shirley's 'Ray tracing in One Weekend' series, as a basis for me to understand the underlying process that comes with image generation from a 3D scene.

This also provides a way to synthetically produce some valuable training data for some vision projects later on, more on that in the future!
